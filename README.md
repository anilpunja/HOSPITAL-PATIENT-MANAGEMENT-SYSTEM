# HOSPITAL-PATIENT-MANAGEMENT-SYSTEM
A console-based patient queue management application built with C
# About the Project
The Hospital Patient Management System is a menu-driven C programming project designed to organise patients waiting for consultation.

It uses a Circular Queue to maintain the order in which patients are called. The first patient added is the first patient called, following the FIFO (First In, First Out) principle.

The application demonstrates C structures, functions, input validation, and file handling. Waiting-patient records can be saved to a file and loaded again when the program starts. Patients who are called for consultation are recorded in a separate history file.
